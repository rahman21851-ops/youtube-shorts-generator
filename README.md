# YouTube Shorts Generator

This web app takes a YouTube link and generates Shorts ideas based on the transcript.

It finds good moments according to the selected content theme.

## Features

- Paste YouTube URL
- Choose theme:
  - General
  - Motivation
  - Business
  - Finance
  - Education
  - Tech
  - Storytelling
  - Custom keywords
- Generate short ideas
- Get start/end timestamps
- Get title ideas
- Get hashtags
- Get FFmpeg command for optional video export

## Important

This project currently generates timestamps and Shorts ideas.

It does not directly download YouTube videos.

Use it only for:

- your own videos
- videos you have permission to edit
- content you are legally allowed to repurpose

## Run locally

Install dependencies:

npm install

Start app:

npm start

Open:

http://localhost:3000

## Note

GitHub Pages will not run this app because it needs Node.js.

To run it online, deploy the repository to a Node.js host such as Render, Railway, or another Node hosting service.
